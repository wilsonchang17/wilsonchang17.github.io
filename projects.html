02 · LLM Security

Scam Shield

A hierarchical scam detection system designed to stay accurate when adversarial messages exploit the weaknesses of individual language models.

Problem
Single-model detectors degraded sharply on adversarially rewritten scam messages.
Build
Selective escalation, multi-model voting, and a 4-bit LoRA fine-tuned LLaMA tie-breaker.
