Research by Chen-Wei (Wilson) Chang

Virginia Tech research on LLM security, adversarial scam detection, ensemble modeling, and robust AI systems that connect academic rigor with production deployment.

Research Focus

Chen-Wei Chang studies how large language models behave under adversarial pressure and how to make them safer for real-world deployment. Wilson Chang's research at Virginia Tech focuses on LLM security, adversarial scam detection, ensemble decision systems, structured perturbation, and deployment-aware evaluation.

Across both academic and applied environments, Chen-Wei (Wilson) Chang investigates how to strengthen model robustness with better training data, stronger evaluation protocols, and hybrid pipelines that blend traditional machine learning with fine-tuned LLMs.

Current themes include adversarial attacks against large language models, AI-enabled scam detection, robust fine-tuning, ensemble methods, and human-usable AI systems for security and analytics.

Academic Publications

Scam Shield: Multi-Model Voting and Fine-Tuned LLMs Against Adversarial Attacks

Chen-Wei (Wilson) Chang, et al.

2025 IEEE International Conference on Big Data (IEEE BigData 2025), Macau, China

Published

Abstract

Scam Shield addresses cybersecurity threats created by adversarial scam messages designed to bypass automated detection. The system combines a four-model ensemble with a fine-tuned LLaMA 3.1 8B Instruct model to improve detection accuracy, strengthen robustness, and stay computationally practical for deployment-oriented security pipelines.

Contributions

  • Designed a hybrid detection system combining four ML models with a fine-tuned LLaMA 8B model.
  • Applied LoRA-based fine-tuning to improve adversarial robustness efficiently.
  • Created a 20K-sample scam dataset with adversarial examples for evaluation.
  • Benchmarked detection performance across multiple scam categories and model families.

Impact

  • Improves scam detection accuracy while controlling deployment cost.
  • Shows how adversarial fine-tuning can harden LLM security systems.
  • Supports practical adoption of AI-assisted cyber-defense workflows.
  • Creates a repeatable benchmark for robust scam detection research.

Exposing LLM Vulnerabilities: Adversarial Scam Detection and Performance

Chen-Wei (Wilson) Chang, et al.

2024 IEEE International Conference on Big Data, Washington, DC, USA

Published

Abstract

This paper examines how adversarial scam messages exploit weaknesses in LLM-based scam classifiers. The work introduces a fine-grained dataset, structured prompt-based adversarial generation, and a comparative evaluation across GPT, Claude, and LLaMA-family models to reveal failure modes and improvement paths.

Contributions

  • Created a labeled dataset containing both original and adversarial scam messages.
  • Designed a structured method for prompt-based adversarial example generation.
  • Benchmarked commercial and open models across multiple scam categories.
  • Documented how adversarial inputs degrade detection quality in security contexts.

Impact

  • Surfaces concrete LLM failure modes in adversarial scam detection.
  • Motivates adversarial training and stronger evaluation practices.
  • Provides practical guidance for teams deploying LLMs in risky environments.
  • Extends the literature on adversarial robustness in NLP and AI safety.

RailEstate: An Interactive System for Metro Linked Property Trends

Chen-Wei (Wilson) Chang, Yu-Chieh Cheng, Yun-En Tsai, Fanglan Chen, Chang-Tien Lu

33rd ACM International Conference on Advances in Geographic Information Systems (SIGSPATIAL '25), Minneapolis, MN, USA

Published

Abstract

RailEstate is a web-based analytics platform that fuses Washington metropolitan housing data with WMATA transit infrastructure to surface metro-linked price trends. It combines spatial databases, forecasting, and a natural-language-to-SQL chatbot to make geospatial housing analysis accessible to non-technical users.

Contributions

  • Deployed a Supabase-hosted PostGIS stack with spatial indexing for low-latency transit analytics.
  • Integrated React, Leaflet, and Recharts for interactive metro-centric visual exploration.
  • Built a LangChain and GPT-powered text-to-SQL workflow for natural-language housing queries.

Impact

  • Enables planners, investors, and residents to interrogate housing trends quickly.
  • Supports data-driven planning with forecast-aware, transit-linked insights.
  • Demonstrates a portable architecture for geospatial intelligence products.
